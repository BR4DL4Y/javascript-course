# First Assignment - HTML & CSS Practice

A modern, responsive, and lightweight practice webpage built from scratch using semantic HTML5 and custom CSS3.

## Features & Technologies
- **Semantic HTML5:** Structured using `<header>`, `<main>`, `<section>`, and `<footer>` tags to improve SEO and accessibility.
- **Modern CSS3 Flexbox:** Clean layout alignment for navigation bars and geometry containers.
- **Smooth Animations:** Custom CSS transitions for hover states, scale effects, and smooth scrolling (`scroll-behavior: smooth`).
- **Catppuccin Palette:** Carefully chosen dark-mode color scheme (`#181825`) with soft pastel accents.
